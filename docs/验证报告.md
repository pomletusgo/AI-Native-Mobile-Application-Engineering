## 说明

- 本工程为手工编写的 `project.pbxproj`（`objectVersion = 56`、`compatibilityVersion = "Xcode 14.0"`），与课程参考案例格式一致。结构检查证明引用自洽；该工程已在 GitHub Actions 的 `macos-15` runner 上真实编译并运行测试，这是比结构检查更强的证据，但仍不等同于在本机 Xcode 中打开、编辑与运行模拟器。
- 单元测试共 77 个方法（Model 9 / Repository 14 / CardHolderViewModel 10 / CardDetailViewModel 9 / PersistentBusinessCardRepository 16 / VCardExporter 19）。相机、OCR、字段抽取与 UI Golden Test 的测试仍待对应周次补充。
- `ScannerEntryView` 仍是扫描入口占位，用模拟识别结果验证 T02/T12，不代表真实 OCR 已实现。Week 3 的相机与 OCR 尚未接线。
- 5.3 只有 VCF 文本生成经过验证；写入系统联系人的 `Contacts` 接入与外发确认 UI 尚未实现，`T19` 的端到端验收未完成。
- 概率性功能（OCR、字段抽取）不使用「通过/失败」结论，而是以 `testcards/ground_truth.json` 统计字段级准确率与缺失字段误报率。
