## 一、演示前提

| 项 | 要求 |
| --- | --- |
| 设备 | 一台能跑 iOS 17+ 模拟器的 Mac（**须带 GUI 的 Xcode**），或一台真 iPhone（Personal Team 免费签名可行） |
| 工程 | `CamCardClone.xcodeproj`，Scheme `CamCardClone`，机型 `iPhone 17`（iOS 27.0 runtime） |
| 存储启动参数 | `-uiTestResetStore` 清空存储；`-uiTestSeedStore` **空库时**写入三张种子名片（朱宏明 / 李娜 / David Chen）。**两者必须同时传**，否则已有的库不为空、种子写不进去 |
| 演示数据 | `testcards/` 的 30 张合成名片（`ground_truth.json` 含 Ground Truth）；拍好的 A4 拼版打印件（`testcards/tools/make_print_sheet.py` 生成） |
| 演示方式 | 建议**录屏为主、关键页截图定格**，与 2026-11-03 的验收方式一致 |

**演示前自检**（Mac 端执行）：

```bash
xcode-select -p                      # 应指向 /Applications/Xcode.app/Contents/Developer
xcrun simctl list runtimes           # 应有 iOS 27.0 runtime
xcrun simctl list devices available  # 应有 iPhone 17
cd CamCardClone && xcodebuild test -scheme CamCardClone -destination 'platform=iOS Simulator,name=iPhone 17'
```
